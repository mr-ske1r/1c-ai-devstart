# Установка и обновление шаблона 1C AI DevStart

> Это инструкция для ИИ-агента. Человеку она не нужна: порядок действий руками — в `README.md`.

Пользователь просит установить в свой проект шаблон Claude Code для разработки на 1С:Предприятие
либо обновить уже установленный. Выполни шаги ниже самостоятельно. Задавай вопросы только там,
где это прямо предписано.

**ЦЕЛЬ:** файлы шаблона лежат в папке проекта, временное скачанное убрано, пользователь знает
следующий шаг.

**ГОТОВО, КОГДА:** при установке — в корне проекта есть `CLAUDE.md`, `.claude/rules/1c-rules.md`
и `.claude/commands/setup-project.md`, а папки `.git` шаблона в проекте нет. При обновлении —
каталог `.claude` заменён свежим, а файлы в корне проекта не изменены.

## Шаг 1. Проверь, куда ставишь

Шаблон ставится в текущую рабочую папку — это будущий каталог проекта 1С.

Остановись и спроси у пользователя путь, если текущая папка — домашний каталог, `Desktop`,
`Downloads`, `Documents`, временный каталог или каталог настроек Claude Code (`~/.claude`,
`%USERPROFILE%\.claude`). Путь не угадывай и папку проекта за пользователя не придумывай.

## Шаг 2. Определи, установка это или обновление

**Пользователь прямо попросил обновить шаблон** — работай в режиме обновления, вопросов не задавай.

Иначе смотри, что в папке. Пусто — обычная установка. Уже есть `CLAUDE.md` или каталог `.claude/` —
шаблон, скорее всего, стоит: **остановись, покажи найденное и спроси**, обновлять или отменить.
Сам не решай.

В режиме обновления на шаге 4 копируй только каталог `.claude`. Файлы в корне проекта
(`CLAUDE.md`, `.mcp.json`, `.gitignore` и прочие) не трогай: они настроены под конкретный проект,
и свежий шаблон их значения не знает.

## Шаг 3. Скачай шаблон

Скачай во временный подкаталог `.devstart-tmp` внутри папки проекта — так не понадобится доступ
за её пределы. Источник — `https://github.com/mr-ske1r/1c-ai-devstart`, ветка `master`. Хватит
последнего среза, история шаблона в проекте не нужна.

Есть `git` — клонируй с глубиной 1. Нет — скачай архив
`https://github.com/mr-ske1r/1c-ai-devstart/archive/refs/heads/master.zip` и распакуй; внутри
архива файлы лежат в папке `1c-ai-devstart-master`, учитывай это в путях на шаге 4.

Средства выбирай по своей системе. Команды для Windows PowerShell:

```powershell
git clone --depth 1 https://github.com/mr-ske1r/1c-ai-devstart.git .devstart-tmp
```

## Шаг 4. Разложи файлы

Скопируй **содержимое** скачанного (а не саму папку) в корень проекта. Не копируй три вещи:
каталог `.git`, а также `README.md` и `install.md` — они описывают сам шаблон и в проекте
не нужны. Скрытые файлы и каталоги, начинающиеся с точки, наоборот, должны попасть в проект:
`.claude`, `.mcp.json.example`, `.gitignore.example`, `CLAUDE.local.md.example`.

Перед копированием убедись, что каталог назначения существует: и `Copy-Item`, и `cp` при
отсутствующем назначении раскладывают файлы иначе, чем ожидается, — `.claude` теряется,
а его содержимое оказывается в корне. Команда для Windows PowerShell:

```powershell
Copy-Item .devstart-tmp\* . -Recurse -Exclude .git, README.md, install.md
```

## Шаг 5. Проверь результат

Убедись, что на месте `CLAUDE.md`, `.claude/rules/1c-rules.md`, `.claude/commands/setup-project.md`,
а `.git`, `README.md` и `install.md` шаблона в проект не попали. В режиме обновления дополнительно
проверь, что файлы в корне проекта остались прежними. Что-то не сошлось — скажи об этом прямо
и не рапортуй об успехе.

## Шаг 6. Убери за собой

Удали `.devstart-tmp` и, если скачивал архив, `devstart.zip`.

## Шаг 7. Передай пользователю следующий шаг

**Перезапустить Claude Code** нужно в обоих режимах: `CLAUDE.md` и `.claude/rules/` читаются
при старте сессии, а за каталогом `.claude/skills/` Claude Code начинает следить только с того
запуска, в котором каталог уже существовал.

После установки добавь второе: **в новой сессии выполнить `/setup-project`** — команда настроит
подключение к базе, выгрузит исходники и заполнит паспорт проекта. Сам её не вызывай: в текущей
сессии этой команды ещё нет.

После обновления `/setup-project` запускать не нужно: подключение и паспорт уже настроены.

Пользователь работает не на Windows — предупреди отдельно: шаблон рассчитан на Windows,
и на другой системе не заработают пакетные операции через конфигуратор (скилл `1c-batch`,
27 скриптов PowerShell) и часть `/setup-project`, которая ищет платформу в `C:\Program Files\1cv8`.
Правила, скиллы, субагенты и работа с базой через MCP от системы не зависят.

ВЫПОЛНЯЙ СЕЙЧАС: пройди шаги 1-7 и доложи результат.
