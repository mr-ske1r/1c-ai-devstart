# Генерация изображения

Единственный сценарий, где codex делает то, чего сессия не умеет вовсе. Работает через
встроенный в codex инструмент генерации — отдельный ключ OpenAI и установка чего-либо
для этого не нужны.

## Шаблон

```bash
codex exec -s workspace-write --skip-git-repo-check -C "$PWD" -o "$ОТВЕТ" - <<'EOF'
Generate an image and save it to disk.

Description: <описание>
Size: <ширина>x<высота> px
Format: png
Save to: <абсолютный путь>

Do not list or scan workspace files. Save the image directly to the path above.
After saving, reply only with the absolute path of the saved file.
EOF
```

Четыре поля — описание, размер, формат, абсолютный путь — собирай **до** запуска. Нет
хотя бы одного, и его нельзя вывести из задачи, — спроси пользователя, а не подставляй своё.

## Почему здесь нельзя read-only

Встроенный инструмент сохраняет картинку не туда, куда попросили, а в каталог самого codex:
`~/.codex/generated_images/<id-сессии>/<файл>.png`. В названный путь codex переносит её
следующим шагом — отдельной командой, то есть записью на диск.

Отсюда два следствия:

1. `-s read-only` не годится — нужен `-s workspace-write`, а если целевой каталог лежит вне
   рабочего, ещё и `--add-dir <КАТАЛОГ>`.
2. Путь сохранения давай абсолютный. Не назовёшь путь — картинка так и останется лежать
   внутри каталога codex.

## Размер: просить надо допустимый

Изображение генерируется не в любом размере. Допустимый: обе стороны кратны 16, максимальная
сторона не больше 3840, всего пикселей от 655 360 до 8 294 400, отношение сторон не круче 3:1.

Ходовые: `1024x1024`, `1536x1024`, `1024x1536`, `2048x2048`, `3840x2160`, `2160x3840`.

Ловушка: недопустимый размер запуск **не роняет**. Попросишь 256×256 — codex сгенерирует
в допустимом размере и уменьшит картинку средствами системы. Файл будет, размер будет верный,
но это пересэмплированное изображение, а не отрисованное в этом размере. Нужна мелкая иконка —
проси 1024×1024 и уменьшай сам тем инструментом, которому доверяешь. Картинки для 1С —
подсистемы, команды, реквизиты «Картинка» — как раз такие: мелкие и в нескольких размерах.

## Прозрачный фон

Встроенный инструмент прозрачность не отдаёт. Обходной путь — генерация на плоском хромакее
и снятие фона локальным скриптом codex'а — требует python с pillow. Прежде чем обещать
пользователю PNG с альфа-каналом, убедись, что окружение это потянет; иначе сразу предлагай
однотонный фон.

## Проверка результата

Здесь текстовый ответ ничего не доказывает: путь в ответе бывает, а файла по нему нет.
После запуска — `ls -la <путь>`, и открой изображение, чтобы увидеть, что нарисовано.
«Codex ответил путём» проверкой не является.
