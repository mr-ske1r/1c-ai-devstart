## Паттерн: комментарии в тексте запроса

В сложном запросе комментируй блоки: зачем нужна таблица, соединение или этап пакета.
При создании объекта `Запрос` пиши комментарий о цели: какие данные нужны и для чего.

```bsl
// Задолженность по контрагентам для блокировки отгрузки
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	Взаиморасчеты.Контрагент КАК Контрагент,
|	Взаиморасчеты.СуммаОстаток КАК Задолженность
|ИЗ
|	// Остатки на дату отгрузки, а не текущие: документ может проводиться задним числом
|	РегистрНакопления.ВзаиморасчетыСКонтрагентами.Остатки(&ДатаОтгрузки,) КАК Взаиморасчеты";
```

**Ловушка:** конструктор запросов при сохранении удаляет все комментарии молча, без
предупреждения. Не храни в комментарии запроса ничего, что нельзя потерять, и не строй
на комментариях механизмы модификации текста (см. паттерн условного ПОМЕСТИТЬ).

## Паттерн: подстановка изменяемого имени в текст-шаблон

Когда имя таблицы или поля известно только во время выполнения, пиши полный текст-шаблон
с плейсхолдером и заменяй его через `СтрЗаменить()`. Текст остаётся целым и читаемым,
а точка изменения — одна и явная.

### Правильно — имя таблицы (по образцу ОбщегоНазначения.СсылкаСуществует из БСП)

```bsl
ТекстЗапроса =
"ВЫБРАТЬ ПЕРВЫЕ 1
|	1 КАК Поле1
|ИЗ
|	&ИмяТаблицы КАК Таблица
|ГДЕ
|	Таблица.Ссылка = &Ссылка";

ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "&ИмяТаблицы", ИмяТаблицыПоСсылке(ПроверяемаяСсылка));

Запрос = Новый Запрос;
Запрос.Текст = ТекстЗапроса;
Запрос.УстановитьПараметр("Ссылка", ПроверяемаяСсылка);
```

В конфигурациях на БСП именно эту задачу — проверку существования ссылки — не решай своим
запросом: вызови готовый `ОбщегоНазначения.СсылкаСуществует(Ссылка)`.

### Правильно — выбор таблицы по условию (плейсхолдер `#`)

```bsl
ТекстЗапроса =
"ВЫБРАТЬ
|	Номенклатура.Наименование КАК НаименованиеТовара,
|	ЕСТЬNULL(ТаблицаОстатков.ВНаличииОстаток, 0) КАК ОстатокТовара
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура
|		ЛЕВОЕ СОЕДИНЕНИЕ #ТаблицаОстатков КАК ТаблицаОстатков
|		ПО Номенклатура.Ссылка = ТаблицаОстатков.Номенклатура";

Если ИспользуетсяАдресноеХранение Тогда
	ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "#ТаблицаОстатков", "РегистрНакопления.ТоварыВЯчейках.Остатки");
Иначе
	ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "#ТаблицаОстатков", "РегистрНакопления.ТоварыНаСкладах.Остатки");
КонецЕсли;
```

### Неправильно — конкатенация куска текста с переменной

```bsl
// ПЛОХО: текст разорван, шаблон не открывается в конструкторе, точка изменения спрятана в середине
ТекстЗапроса =
"ВЫБРАТЬ
|	Номенклатура.Наименование КАК Наименование,
|	Номенклатура." + ИмяПоляКод + " КАК КодАртикул
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура";
```

Значения (не имена!) в текст не подставляй никогда — только через `УстановитьПараметр()`
(норма — в `.claude/rules/1c-rules.md`; паттерн параметризации — в `structure.md`).

## Паттерн: условное помещение во временную таблицу

Когда результат по флагу выгружается либо во временную таблицу, либо напрямую: пиши
`ПОМЕСТИТЬ` в тексте запроса и удаляй его заменой, если не нужен.

### Правильно

```bsl
ТекстЗапроса =
"ВЫБРАТЬ
|	Контрагенты.Ссылка КАК Ссылка
|ПОМЕСТИТЬ втКонтрагенты
|ИЗ
|	Справочник.Контрагенты КАК Контрагенты";

Если НЕ ВыгрузитьВоВременнуюТаблицу Тогда
	ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "ПОМЕСТИТЬ втКонтрагенты", "");
КонецЕсли;
```

### Неправильно

```bsl
// ПЛОХО: «раскомментирование» заменой. Конструктор удалит комментарий — механизм сломается молча
ТекстЗапроса =
"ВЫБРАТЬ
|	Контрагенты.Ссылка КАК Ссылка
|	// ПОМЕСТИТЬ втКонтрагенты
|ИЗ
|	Справочник.Контрагенты КАК Контрагенты";

Если ВыгрузитьВоВременнуюТаблицу Тогда
	ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "// ПОМЕСТИТЬ", "ПОМЕСТИТЬ");
КонецЕсли;
```

## Паттерн: сборка пакета из целых запросов

Условную часть пакета добавляй целым запросом; разделитель пакета — отдельная строка,
а не хвост одного из кусков. Каждый элемент сборки открывается в конструкторе сам по себе.

### Правильно

```bsl
Разделитель =
"
|;
|////////////////////////////////////////////////////////////////////////////////
|";

ТекстыЗапросовПакета = Новый Массив;

Если ИспользоватьУпаковки Тогда
	ТекстыЗапросовПакета.Добавить(
	"ВЫБРАТЬ
	|	Упаковки.Ссылка КАК Ссылка
	|ИЗ
	|	Справочник.Упаковки КАК Упаковки");
КонецЕсли;

ТекстыЗапросовПакета.Добавить(
"ВЫБРАТЬ
|	Номенклатура.Ссылка КАК Ссылка
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура");

Запрос = Новый Запрос;
Запрос.Текст = СтрСоединить(ТекстыЗапросовПакета, Разделитель);
```

### Неправильно

```bsl
// ПЛОХО: разделитель приклеен к условному куску; при выключенном флаге пакет начинается
// с мусора, при добавлении третьего запроса логика разделителей расползается по условиям
ТекстЗапроса = " ";
Если ИспользоватьУпаковки Тогда
	ТекстЗапроса =
	"ВЫБРАТЬ
	|	Упаковки.Ссылка КАК Ссылка
	|ИЗ
	|	Справочник.Упаковки КАК Упаковки;
	|////////////////////////////////////////////////////////////////////////////////
	|";
КонецЕсли;

ТекстЗапроса = ТекстЗапроса +
"ВЫБРАТЬ
|	Номенклатура.Ссылка КАК Ссылка
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура";
```

Для пакета с временными таблицами, живущими между несколькими объектами `Запрос`,
используй `МенеджерВременныхТаблиц` — см. `structure.md`.
