# Маркеры доработок

> Обязательные нормы — в разделе «Маркеры доработок» файла
> `.claude/rules/1c-rules.md`. Здесь только выбор и форма BSL-шаблона.
>
> Файл применим, только когда настройка «Маркеры доработок» в `CLAUDE.md`
> распространяется на правимое место. При `не используются` шаблонов ниже
> не существует; при `только типовой код основной конфигурации` из них
> действует одна «Прямая замена типового кода».

## Заполнение

1. `COMPANY` и формат маркера бери из `CLAUDE.md`.
2. `DEVELOPER` бери из `CLAUDE.local.md`; если значения нет, запроси его.
3. `DATE` — текущая дата в формате `ДД.ММ.ГГГГ`.
4. `TASK` сначала ищи в запросе, затем в пути к брифу или папке задачи;
   приведи к формату из `CLAUDE.md`.
5. Если номер не найден, запроси его. После подтверждения работы без задачи
   убери весь последний сегмент вместе с точкой с запятой.

Перед вставкой замени `{COMMENT_OPEN}` и `{COMMENT_CLOSE}` полностью
сформированными строками.

## Выбор шаблона

| Изменяемое место | Используй |
|---|---|
| Типовой код в основной конфигурации | Прямая замена |
| Новый верхнеуровневый алгоритм команды | Одна пара вокруг алгоритма |
| Фрагмент кода коллеги | Локальная пара |
| `&Перед`, `&После`, `&Вместо` | Шаблон кода команды |
| Перехватчик, привязанный к событию формы («Перед», «После», «Вместо») | Шаблон кода команды — тело обычное, директивы расширения в нём нет |
| `&ИзменениеИКонтроль` | Директивы платформы и вставляемые COMMENT-маркеры |

## Паттерн: прямая замена типового кода

```bsl
{COMMENT_OPEN}
// Сумма = Количество + Цена;
Сумма = Количество * Цена;
{COMMENT_CLOSE}
```

Заголовок нового метода в типовом модуле оставляй вне пары; маркерами
оборачивай его тело.

## Паттерн: верхнеуровневый алгоритм команды

```bsl
&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи(Отказ)

	{COMMENT_OPEN}
	ПроверитьДополнительныеУсловия(Отказ);
	ЗаполнитьСлужебныеДанные();
	{COMMENT_CLOSE}

КонецПроцедуры
```

Для `&После` и `&Вместо` пара размещается так же внутри тела
перехватчика. Вспомогательные методы повторно не маркируются.

## Паттерн: локальная правка кода коллеги

```bsl
// +++ Компания; Коля; 10.07.2026; DEV-0002
Параметры = ПодготовитьПараметры();
// --- Компания; Коля; 10.07.2026; DEV-0002

// +++ Компания; Иван; 25.07.2026; DEV-0003
Параметры.Вставить("УчитыватьРезерв", Истина);
// --- Компания; Иван; 25.07.2026; DEV-0003
```

## Паттерн: `&ИзменениеИКонтроль`

Простая вставка:

```bsl
#Вставка
{COMMENT_OPEN}
ПересчитатьРезервы();
{COMMENT_CLOSE}
#КонецВставки
```

Замена:

```bsl
#Вставка
{COMMENT_OPEN}
#КонецВставки

#Удаление
Сумма = Количество + Цена;
#КонецУдаления

#Вставка
Сумма = Количество * Цена;
{COMMENT_CLOSE}
#КонецВставки
```

Чистое удаление:

```bsl
#Вставка
{COMMENT_OPEN}
#КонецВставки

#Удаление
ЗаписатьОтладочныеДанные();
#КонецУдаления

#Вставка
{COMMENT_CLOSE}
#КонецВставки
```

Не добавляй `COMMENT_*` обычными строками среди контролируемой копии
типового метода: они сами являются вставкой.
