## Метки применимости

- `NEW-85` — новое проектирование для интерфейса 8.5.
- `MIGRATION-85` — адаптация существующего решения.
- `DUAL-TAXI-85` — один артефакт работает в «Такси» и 8.5.

Метки независимы. Применяй строку только когда задача совпадает хотя бы с одной её меткой;
для dual-артефакта приоритет имеют строки с `DUAL-TAXI-85`.

## Целевые экраны

| Цель | Размер | Что проверить | Метки |
|---|---:|---|---|
| Рекомендуемый desktop | `1920×1080`, рабочая область около `1920×940` | основные сценарии без горизонтальной прокрутки формы | `NEW-85`, `MIGRATION-85` |
| Минимальный desktop | `1280×768` | доступность сценария после платформенной адаптации | `NEW-85`, `MIGRATION-85` |
| Рекомендуемый mobile | `375×812` логических пикселей | элементы формы без горизонтальной прокрутки | `NEW-85`, `MIGRATION-85` |
| Минимальный mobile | `320×568` логических пикселей | сценарий остаётся выполнимым | `NEW-85`, `MIGRATION-85` |

Для desktop учитывай эффективное, а не только физическое разрешение:
`эффективное = физическое / коэффициент масштаба ОС`. Проверяй обычный и компактный вариант
масштаба, когда они входят в целевую среду. `mobile` конкретизируй: мобильный клиент, мобильное
приложение или веб-клиент на телефоне.

## Порядок данных и архетип формы

### Расставь данные по сценарию

| Размещение | Признаки реквизита | Метки |
|---|---|---|
| начало формы, первая колонка | важный, вводится вручную, обязательный | `NEW-85`, `MIGRATION-85` |
| ниже, следующие колонки или вкладки | вспомогательный, малозначимый, обычно заполняется автоматически, необязательный | `NEW-85`, `MIGRATION-85` |
| рядом или в одной группе | реквизиты близки по смыслу или зависят друг от друга | `NEW-85`, `MIGRATION-85` |
| не менее 50% ширины формы | важный крупный элемент, занимающий ширину/высоту: многострочное поле, планировщик и т. п. | `NEW-85`, `MIGRATION-85` |

Порядок элементов следует порядку заполнения. Несколько крупных элементов размещай на страницах;
свёртываемые группы допустимы, когда они лучше поддерживают сценарий.

### Выбери один из трёх архетипов

| Условие | Архетип и вертикальный порядок | Метки |
|---|---|---|
| Есть поля и важная таблица/крупный элемент; поля, итоги и подвал суммарно занимают не более `4` строк | поля → таблица/страницы → итоги → подвал | `NEW-85`, `MIGRATION-85` |
| Таблица или крупный элемент не важны при открытии | первая страница с полями → отдельные страницы крупных элементов → подвал | `NEW-85`, `MIGRATION-85` |
| Таблиц и крупных элементов нет | поля в одной или адаптивных колонках → подвал | `NEW-85`, `MIGRATION-85` |

Однотипные по прикладному назначению объекты конфигурации оформляй одинаковым архетипом.
Для колонок реквизитов используй платформенную адаптацию, а не отдельную ручную раскладку на
каждое разрешение.

## Поля, переключатели и группы

| Ситуация | Решение | Метки |
|---|---|---|
| Заголовок элемента | краткий и ёмкий | `NEW-85`, `MIGRATION-85` |
| Число с короткой единицей (`%`, `руб.`) | помести постфикс в маску поля | `NEW-85`, `MIGRATION-85` |
| Многострочное поле с кнопкой выбора | перенеси действие в контекстное меню | `MIGRATION-85` |
| Выпадающий список или ссылочный тип в многострочном поле | замени компоновку: список в 8.5 не отображается | `MIGRATION-85` |
| Внутренние кнопки поля | не более одной, не считая очистки | `NEW-85`, `MIGRATION-85` |
| Однотипные числовые поля в одной группе | текст справа | `NEW-85`, `MIGRATION-85` |
| Разнотипные или отдельные числовые поля | текст слева | `NEW-85`, `MIGRATION-85` |
| Поле поиска | без заголовка; картинка `БиблиотекаКартинок.Найти`; подсказка `Поиск`; кнопка очистки | `NEW-85`, `MIGRATION-85` |
| Диапазон дат с заголовками `с`/`по` | `Дата начала` / `Дата окончания` | `MIGRATION-85` |
| Переключатель с более чем 7 значениями | поле ввода с выбором из списка | `NEW-85`, `MIGRATION-85` |
| Горизонтальный переключатель | вид `Тумблер` | `NEW-85`, `MIGRATION-85` |

Выбор между флажком и выключателем:

- флажок — пользователь выбирает варианты, затем подтверждает действие;
- выключатель — состояние меняется сразу и не требует отдельной кнопки;
- не используй флажок вида `Тумблер`: выбери `Флажок` или `Выключатель` по поведению.

Для группы с заголовком без соседних заголовочных групп предпочитай `Отображение=Авто`.
Если заголовки показывают вложенность, соблюдай уровни `СильноеВыделение → ОбычноеВыделение →
СлабоеВыделение → Нет`; при навигаторе начинай с обычного выделения. Не помещай в одну
горизонтальную группу обычные элементы и страницы с вертикальными закладками.

## Команды и кнопки

### Размести по назначению

| Назначение | Место и свойство | Метки |
|---|---|---|
| завершение, закрытие, выбор, запись/проведение как часть терминального действия | нижняя панель, `НазначениеДействия=Завершение` | `NEW-85`, `MIGRATION-85` |
| действие над формой целиком | верхняя панель, `НазначениеДействия=Обычное` | `NEW-85`, `MIGRATION-85` |
| создание новой сущности | заголовок формы, `НазначениеДействия=Создание` | `NEW-85`, `MIGRATION-85` |
| действие над элементом или таблицей | панель непосредственно над элементом | `NEW-85`, `MIGRATION-85` |

- В верхней командной панели оставляй не более `4` наиболее частотных команд; остальные — в
  `Еще`.
- В диалоговом окне не дублируй стандартное закрытие кнопками `Отмена`/`Закрыть`.
- Вместо `OK` используй глагол действия: `Сохранить`, `Выбрать`, `Применить`.
- Для кнопки только с картинкой требуются однозначная общепринятая картинка и подсказка; иначе
  показывай заголовок.
- Переход оформляй кнопкой вида `Гиперссылка`. Менее важное действие в ряду кнопок — обычная
  кнопка с `Важность=Дополнительная`.
- В нижней панели: одна главная кнопка → обычные → дополнительные → `Еще`. В пошаговом сценарии
  главная кнопка соответствует следующему действию и может быть справа.

Для команды строки заполняй `ИспользуемаяТаблица` и указывай использование текущей или
выделенных строк. При миграции проверь обращения к стандартным кнопкам списка по имени: в 8.5
они находятся в панели основной таблицы и получают префикс имени таблицы. Изменение BSL выполняй
через `form-work`, здесь только зафиксируй отклонение. `[MIGRATION-85, DUAL-TAXI-85]`

## Таблицы и крупные элементы

- Важную, вручную заполняемую и обязательную таблицу показывай при открытии формы; второстепенные
  таблицы выноси на следующие страницы или в свёртываемые группы. `[NEW-85, MIGRATION-85]`
- При рекомендуемом разрешении обеспечивай не менее `5` одновременно видимых строк. Если над
  таблицей поля оставляют меньше 5 строк на экране высотой 1080 при обычном масштабе, попробуй
  `ПоложениеЗаголовковПодчиненных=СлеваЕслиВозможно`. `[NEW-85, MIGRATION-85]`
- Под таблицей размещай только связанные итоги: справа, полем надписи; для результата используй
  `ЗаголовокВторогоУровня`. Подвал — ниже итогов. `[NEW-85, MIGRATION-85]`
- Ширину колонок начинай с `РастягиватьПоГоризонтали=Авто`, `Ширина=0`; заголовок не участвует
  в авторасчёте, поэтому проверяй его читаемость. `[MIGRATION-85]`
- Закреплённые слева и справа колонки суммарно должны занимать не более `50%` ширины таблицы.
  `[NEW-85, MIGRATION-85]`
- Для множественного выделения проверь фиксированную ширину таблицы и горизонтальную прокрутку;
  не ставь флажок первой колонкой, если он дублирует выбор строк. `[MIGRATION-85]`
- Команды над выделенными строками должны использовать `ПолучитьСтрокиДляОбработки()`, а не
  только `ВыделенныеСтроки`; код передай в `form-work`. `[MIGRATION-85]`
- Состояние, показанное отметкой 8.5, продублируй текстом/флажком для «Такси».
  `[DUAL-TAXI-85]`
- Картинки через условное оформление или `ПриПолученииДанных`, а также высокие картинки в
  многострочных строках отдельно проверь в «Такси»; при несовместимости выбери другое место
  отображения. `[DUAL-TAXI-85]`

Мастер-детали: мастер-таблица слева, детали справа; задай `НачальнаяАктивизацияСтроки`, а у
мастер-таблицы — `ОтображениеГиперссылкиЯчейки=НеОтображать`. `[NEW-85, MIGRATION-85]`

Если табличный документ используется для ввода данных, задавай редактируемым ячейкам
`ТипОтображенияРедактируемойЯчейки=КакПолеВвода`. При миграции проверь подсказки ячеек,
`ПолучитьВыделенныеОбласти()` и `ТекущаяОбласть`; визуальный слой табличного документа смотри
в `visual-style.md`. `[NEW-85, MIGRATION-85]`

Для отчётов проверь программную работу с автоматически созданными элементами пользовательских
настроек и макеты заголовков группировок/итогов: в 8.5 они генерируются иначе. `[MIGRATION-85]`

## Прокрутка и адаптивность

- Не проектируй горизонтальную прокрутку формы на целевых разрешениях.
- Избегай одновременно двух вертикальных полос, например формы и таблицы.
- `ВертикальнаяПрокруткаПриСжатии=Истина` уместно у группы, если внутри нет собственного
  вертикально прокручиваемого элемента.
- Вертикальная прокрутка всей формы допустима для большого объёма реквизитов или длинного
  документа, когда устранение прокрутки неоправданно усложнит интерфейс.
- Не называй результат проверенным на разрешении или теме без запуска клиента; статический
  вывод помечай как расчётный.

## Чек-лист ревью

- [ ] Фактический режим интерфейса прочитан из конфигурации.
- [ ] Состояние проекта и совместимость артефакта классифицированы отдельно.
- [ ] Архетип выбран по важности крупного элемента и лимиту `4` строк.
- [ ] На desktop видно не менее `5` строк важной таблицы.
- [ ] Верхних кнопок не более `4`; остальные осмысленно ушли в `Еще`.
- [ ] Закреплённые колонки занимают не более `50%` таблицы.
- [ ] На целевых разрешениях нет горизонтальной и множественной вертикальной прокрутки.
- [ ] Dual-ограничения проверены только для формы, действительно общей с «Такси».
- [ ] Статическая оценка не выдана за запуск клиента.
