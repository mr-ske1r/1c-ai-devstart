# Визуальный стиль интерфейса «Версия 8.5»

## Базовый выбор

1. Начинай со значения `Авто`, если свойство его поддерживает.
2. Отклоняйся от `Авто` только ради конкретного пользовательского результата, который проверен
   в целевых темах и клиентах.
3. Для dual-артефакта применяй только рекомендации с меткой `DUAL-TAXI-85`. Если одно оформление
   нельзя сделать качественным в обоих интерфейсах, выбирай две формы или два макета, а не
   программную перекраску при открытии.

## Цвета и шрифты

| Проверка | Изменение | Метки |
|---|---|---|
| Цвет задан как `WebЦвет`, `WindowsЦвет` или устаревший стилевой цвет | замени цветом палитры интерфейса | `MIGRATION-85` |
| `ОченьКрупныйШрифтТекста` | `ЗаголовокПервогоУровня` | `MIGRATION-85` |
| `КрупныйШрифтТекста` | `ТекстПервогоУровня` | `MIGRATION-85` |
| `ОбычныйШрифтТекста` или `ШрифтТекста` | `ТекстТретьегоУровня` | `MIGRATION-85` |
| `МелкийШрифтТекста` | `ПодзаголовокПервогоУровня` | `MIGRATION-85` |
| У поля ввода задан собственный шрифт | замени на `РазмерТекста=Уменьшенный` при размере меньше 10 или `Увеличенный` при размере больше 10 | `MIGRATION-85` |

Шрифты `ЗаголовокПервогоУровня` … `ЗаголовокПятогоУровня` в надписях используй только для
особо важной информации, например итогов. Не создавай визуальную иерархию ручными шрифтами,
когда её выражает системный уровень текста.

Для макета оформления отчёта 8.5 исходная точка: отступы слева/справа `0,5`, сверху/снизу `6`,
шрифт `Roboto 9 pt`. Проверяй результат в конкретном табличном документе, а не переноси значения
на произвольные элементы формы. `[NEW-85, MIGRATION-85]`

## Картинки

### Порядок выбора

1. Ищи картинку в библиотеке платформы.
2. Если подходящей нет, выбирай единообразную векторную иконку из лицензированного набора.
3. Сохраняй картинку в библиотеке картинок конфигурации; абсолютные картинки из свойств элементов
   переноси туда.

### Тип и темы

- По умолчанию используй векторную монохромную картинку с `Тип=Шаблонная`: платформа сама
  окрашивает её под элемент и тему. `[NEW-85, MIGRATION-85]`
- `Тип=Цветная` нужен, только если цвет несёт смысл или различает состояния. Для цветной картинки
  подготовь варианты для светлой и тёмной темы. `[NEW-85, MIGRATION-85]`
- Растровую картинку заменяй векторной. Если это невозможно, проверь масштабирование на целевых
  плотностях и обеих темах. `[NEW-85, MIGRATION-85]`
- Логотип, заставка и картинка основного раздела должны быть векторными с вариантами тем либо
  шаблонными для любой темы. `[NEW-85, MIGRATION-85]`
- Картинки-коллекции с определением элементов по размеру ячейки проверяй вручную после конвертации.
  `[MIGRATION-85]`

Не копируй цвет картинки из темы вручную. Если нужна смысловая раскраска, используй согласованный
набор палитры и проверь пару светлая/тёмная тема.

## HTML-поле

- Генерируй цвета через CSS-переменные интерфейса; практический набор и пример —
  `html-colors.md`. `[NEW-85, MIGRATION-85]`
- Эта схема не предназначена для одного HTML-поля, общего для «Такси» и 8.5. Для такого случая
  выбирай отдельные формы. `[DUAL-TAXI-85]`
- Если поле HTML не является редактором, отключай его рамку. `[NEW-85, MIGRATION-85]`
- Проверь контраст текста, ссылок, границ, hover/selected-состояний и фона в обеих темах.

`html-colors.md` читай только при генерации или ревью HTML. Для обычных элементов формы цвета
задаются платформенной палитрой и свойствами, а не CSS.

## Табличный документ

- Для ввода данных помечай редактируемые ячейки
  `ТипОтображенияРедактируемойЯчейки=КакПолеВвода`. `[NEW-85, MIGRATION-85]`
- Для макета ввода используй исходную точку отчётов: отступы `0,5 / 0,5 / 6 / 6`,
  `Roboto 9 pt`; затем проверяй печать и экран. `[NEW-85, MIGRATION-85]`
- В общем для «Такси» и 8.5 табличном документе при тёмном фоне ячейки/рисунка задавай светлый
  цвет текста явно, а не `Авто`. `[DUAL-TAXI-85]`

## Матрица визуальной проверки

| Объект | Светлая | Тёмная | Что считать дефектом |
|---|---|---|---|
| текст и фон | проверить | проверить | недостаточный контраст, ручной цвет не адаптируется |
| шаблонные картинки | проверить | проверить | исчезают, сливаются с фоном, неверный смысл |
| цветные картинки | проверить | проверить | нет варианта темы, цвет теряет смысл |
| HTML | проверить | проверить | абсолютные цвета, нечитабельные ссылки/состояния |
| табличный документ | проверить | проверить | текст теряется на тёмном фоне |

Каждую клетку помечай как расчётную, подтверждённую запуском или не проверенную.
