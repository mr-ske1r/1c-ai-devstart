# CSS-цвета HTML-поля в интерфейсе «Версия 8.5»

Используй этот reference только для HTML, отображаемого в форме 8.5. Не переноси CSS-переменные
в свойства обычных элементов формы. Если не указано иное, рекомендации имеют метки
`NEW-85`, `MIGRATION-85`.

## Ограничение совместимости

CSS-переменные 8.5 не являются решением для одного HTML-поля, общего с «Такси». Если HTML должен
работать в обоих интерфейсах, выбери отдельные формы/HTML-макеты либо нейтральное оформление,
которое подтверждено запуском в обоих интерфейсах. `[DUAL-TAXI-85]`

## Семейства переменных

| Семейство | Назначение |
|---|---|
| `--colorText10` … `--colorText90` | уровни текста; выбирай уровень по контрасту и важности |
| `--colorBack10` … `--colorBack90` | нейтральные фоны и границы |
| `--colorGray10` … `--colorGray90` | нейтральные графические элементы |
| `--colorAdditional` | дополнительный контрастный фон |
| `--colorBrand110` … `--colorBrand190` | жёлтая брендовая шкала |
| `--colorBrand210` … `--colorBrand290` | синяя брендовая шкала |
| `--colorRed10` … `--colorRed90` | ошибка, опасность, отрицательное состояние |
| `--colorOrange10` … `--colorOrange90` | предупреждение или промежуточное состояние |
| `--colorYellow10` … `--colorYellow90` | внимание, подсветка |
| `--colorGreen10` … `--colorGreen90` | успех, доступность, положительное состояние |
| `--colorLightBlue10` … `--colorLightBlue90` | информация, мягкий акцент |
| `--colorBlue10` … `--colorBlue90` | действие, ссылка, основной акцент |
| `--colorViolet10` … `--colorViolet90` | дополнительный смысловой акцент |
| `--colorPurple10` … `--colorPurple90` | дополнительный смысловой акцент |
| `--colorPink10` … `--colorPink90` | дополнительный смысловой акцент |

Суффикс задаёт ступень шкалы, но не гарантирует достаточный контраст для любой пары. Не выбирай
цвет только по номеру: проверяй текст/фон в обеих темах и в реальном клиенте.

## Паттерн использования

```html
<section class="notice">
  <strong>Требуется внимание</strong>
  <p>Проверьте заполнение данных.</p>
</section>

<style>
  .notice {
    color: var(--colorText90);
    background: var(--colorYellow20);
    border: 1px solid var(--colorYellow50);
  }
</style>
```

Переменные автоматически получают значения текущей темы. Не добавляй рядом абсолютный цвет,
который перекрывает эту адаптацию.

## Как выбрать пару

1. Определи семантику: обычный текст, фон, действие, информация, предупреждение, ошибка, успех.
2. Выбери соответствующее семейство.
3. Начни с нейтрального текста и светлого оттенка фона; насыщенный оттенок оставь для границы,
   маркера или небольшого акцента.
4. Проверь светлую и тёмную темы фактическим запуском.
5. Если контраст нельзя подтвердить, пометь клетку `не проверено`, а не фиксируй абсолютные HEX.

## Чего здесь намеренно нет

- полного каталога всех пар светлой/тёмной темы;
- копии таблицы значений из ИТС;
- обещания, что конкретный HEX стабилен между версиями платформы;
- CSS для «Такси».

Когда нужен редкий оттенок или точное текущее значение, сверяйся с официальной документацией
той версии платформы, на которой будет работать приложение.
